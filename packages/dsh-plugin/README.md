# 毕业论文格式检查（DeepSeek Harness 插件）

让 DeepSeek Harness 按学校的格式规范，自动检查本科毕业论文（.docx / .doc）的排版。
检查完全在本机进行，论文不会上传到任何地方。

对模型说一句“检查一下 D:\论文\张三-毕业论文.docx 的格式”，它会调用本插件，返回一份按问题分组的报告：

```
- 结果：105 个错误，30 个警告，0 个提示（相同问题已合并）

## 中文摘要与关键词
- [错误] 摘要正文行距应为固定值 20 磅，实际为1.5 倍行距
  - 第 38 段：摘 要：随着互联网技术的发展，在线考试已成为…

## 正文各级标题
- [错误] 一级标题首行缩进应为2 字符，实际为0 字符（共 7 处）
  - 第 116 段：一、引言
  - 第 125 段：二、 系统关键技术
  - …其余 5 处略
- [错误] 二级标题序号后面不空格（共 7 处）
  - 第 120 段：（二） 开发现状
  - …
```

## 能检查什么

| 规则 | 内容 |
|---|---|
| 页面设置 | 纸张大小、上下左右页边距、装订线 |
| 题目与署名 | 中英文题目字体字号、署名行与指导教师行的格式 |
| 中英文摘要 | 标签写法、字体字号行距缩进、字数；关键词个数、分隔符、英文关键词大小写 |
| 目录 | 是否自动生成、级数、是否包含参考文献与致谢 |
| 各级标题 | 字体字号加粗、缩进、段前段后、末尾标点、序号格式与连续性 |
| 正文 | 中西文字体、字号、行距、首行缩进（能识别用空格冒充的缩进）、总字数 |
| 图表题注 | 字体字号对齐、编号连续、表题在表上、图题在图下、正文是否引用 |
| 参考文献 | 篇数、英文篇数、编号、文献类型标识、期刊页码、结尾标点、正文引用顺序 |
| 数字与标点 | 全角数字、用“--”代替破折号、千分位逗号等 |

段落字体字号按 Word 的样式继承规则计算（文档默认 → 样式链 → 自动编号 → 直接格式），与在 Word 里看到的一致。

插件同时提供 `thesis_read_section` 工具，把摘要、正文、参考文献等部分的纯文本交给模型，让它审阅不适合写成固定规则的内容，例如摘要是否交代了背景与技术路线、参考文献是否过旧。

## 安装

1. 在 DeepSeek Harness 的 **插件** 页面按包名 `dsh-plugin-thesis-format` 安装，或用命令行安装：

   ```bash
   dsh plugin --profile <你的 profile 名> add dsh-plugin-thesis-format
   ```

2. 重启 dsh（开启热重载时立即生效）。

需要 Node.js 24 及以上（dsh 自带）。检查 .doc 文件时，插件会先把它临时转换成 .docx，不改动原文件。转换需要本机安装 **Microsoft Word**（Windows）或 **LibreOffice**；只检查 .docx 则不需要。

## 内置规范

目前内置一份：**蚌埠工商学院 计算机科学与技术专业 毕业设计（论文）**，适用于 2025、2026 届，id 为 `bbctb-cs`。它是根据学校的 Word 模板逐条整理的，每一项都注明了模板原文。

## 用于其他学校或专业

各校的格式要求大同小异，差别主要在字体字号、页边距、标题编号方式和参考文献数量等。为本校写一份规范的步骤如下：

1. 复制插件目录 `specs/bbctb-cs.yaml`，改名为本校规范，例如 `D:\规范\my-school.yaml`。
2. 对照学校模板修改与内置规范不同的项目。文件里每一项都附有模板原文注释，照着改即可：
   - 字号可写“小四”“五号”，也可写磅值；
   - 字体可写中文名或英文名（宋体 = SimSun）；
   - 不需要的检查写进 `disabledRules`，例如 `disabledRules: [text-hygiene]`。
3. 选一种方式使用这份规范：
   - 对模型说明：“按 D:\规范\my-school.yaml 检查这篇论文”；
   - 或把本插件的 `spec` 配置改为该文件的绝对路径（见下方“配置”），以后默认使用它。

标题编号方式（“一、”“（一）”“1.”“（1）”）和摘要、目录、致谢、参考文献等部分的识别目前按常见的中文本科论文写法实现。如果你们学校的结构差别较大，欢迎到仓库提 issue，并附上模板，去掉个人信息即可。

## 暂不检查

页码位置、页眉页脚、脚注、表格三线边框、分页。这些信息需要 Word 的排版引擎才能拿到。

## 配置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `spec` | `bbctb-cs` | 默认使用的规范：内置 id，或 YAML 文件的绝对路径 |

在 profile 的 `cordis.patch.yml` 里按 id 覆盖本插件的配置：

```yaml
- id: thesis-format-check
  name: dsh-plugin-thesis-format
  config:
    spec: D:/规范/my-school.yaml
```
